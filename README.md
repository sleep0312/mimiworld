# 米米世界 (MimiWorld)

> 一个以「米」为主题的中型 Minecraft Forge 模组：新增围绕稻米展开的材料、机器、装备、生物与 Boss，并附带「米米维度」与「残堕界」两个独立维度。

A medium-sized rice-themed Minecraft Forge mod that adds a full progression of rice materials, machines, gear, creatures and bosses, plus two standalone dimensions: the "Mimi" dimension and the "Remnant Fallen" realm.

---

## 简介

米米世界把原版 Minecraft 的整套玩法「米化」：从种植、加工、冶炼到制造成品装备，构建了一条完整的稻米产业链；同时新增了数十种米主题生物与七个可挑战的 Boss。模组大量使用 [GeckoLib](https://github.com/bernie-g/geckolib) 制作自定义 3D 模型与动画，并配套数据包驱动的维度、群系与结构生成。

- 模组 ID：`mimiworld`
- 目标平台：Minecraft **1.20.1** / Minecraft Forge **47.4.10+**
- 硬性前置：**GeckoLib 4.7+**（开发版本 4.8.4）
- 版本：1.0.0

## 内容总览

### 农业与材料体系

- **米树与米草**：米原木、米木板、米树叶、米树苗、米草，可自然生成米树林。
- **410+ 种物品**：从 `米 → 熟米 → 米团` 的基础食物链，到结晶米、可燃米、米麻、米网、米饭合金等各阶段中间材料，构成多级加工体系。
- **9 级装备材料链**：饭晶 → 超结晶 → 饭晶合金 → 超重结晶 → 复合米饭 → 清洁复合 → 超懒合金 → 最懒天堕 → 残堕，每级含剑 / 弓 / 全套盔甲 / 镐 / 箭等成套装备；另有「残堕宗罪」套装与「最懒天堕」套装等终局装备，以及米米神翼（鞘翅类）系列。
- **特色消耗品**：米米图腾（免死）、米米之眼、米米传送器、香袋调料、各式米主题料理等。
- **深染系列**：基于染液与残堕材料的深染物品线。

### 加工与工作方块（60+ 种方块）

模组提供大量功能性工作方块：

- 造米机、锤米台 / 高级锤米台
- 电离台、沉淀台、离解台、碾磨台、杵界台、凝锭台
- 铸剑台、铸甲台、铸弓台、淬剑台、汲血台
- 搅碎器、搅拌器、多输入 / 双输入处理器、栅格合成台
- 煮锅系列：小煮锅 → 煮锅 → 大煮锅 → 超大煮锅 → 巨无霸大大大煮锅，另有铁锅、烤箱、锅 / 大锅等烹饪设备
- 堕落台、残堕界传送门等仪式 / 传送设施

### 生物（43 种实体，37 枚生物蛋）

- **友好生物**：米羊羊、啄米鸡、米哞牛、米哼猪、米傀儡、嗥米狼、米莱马。
- **水生生物**：贪米鱼、喷米鱼（可用水桶捕捞，生成于河流 / 海洋，经数据包 biome modifier 注入）。
- **敌对生物**：盗米者、黏米之蛛、米米骷髅、糊米古尸、爪巴米者、米巫、没米入、爆烈米灵、雕米骷髅、米哼猪尸、米魂、界天米、污棘花、混沌虚无触、堕落米凤、化灵米、浅染鲛、望米伤鲛、米蜃、懒精灵、哮噬米狼鹫等。
- **Boss 阵容**（各具独立技能、动画与专属掉落）：
  1. 米米猴王
  2. 饭晶虎王
  3. 超晶牛王
  4. 重晶兔王
  5. 复晶天青蟒
  6. 清洁长命夔
  7. 最懒终末龙

  另有召唤器（小型 / 中型 / 大型 / 最懒召唤器）与召唤核心三级链（胚 → 粗制胚 → 核心）用于按需召唤。

### 维度与世界生成

- **米米维度**（`mimiworld:mimi_dimension`）：米米平原群系与米树地物生成，通过「米米传送器」进入。
- **残堕界**（`mimiworld:remnant_fallen_realm`）：终局维度，含残堕荒原群系与残堕深渊岩地形，通过「残堕界传送门」进入，有独立的敌对生物生成规则。
- **米米宝藏结构**：数据包驱动的刷怪笼宝库——10 份结构 NBT 对应 10 种固定怪物变体，经模板池随机选取，宝箱战利品表与怪物一一对应。

### 战斗系统

- **自定义伤害类型**：重晶兔王砸地、终末龙光束 / 龙息 / 冲撞等独立伤害，无视护甲的伤害归入原版 `bypasses_armor` 标签。
- **自定义药水效果**：腥红烛照、蟒缠、创造飞行等，Boss 技能增益以可见 buff 图标呈现。
- **自定义箭矢**：独立实体与物品实现，固定伤害、落地可回收、可选兼容「无限」附魔。
- **48 个 GeckoLib 模型 + 43 个动画文件**：全部生物、立体盔甲与动画方块均由 Blockbench 制作并经 GeckoLib 渲染。

### 数据驱动内容

- 约 250+ 条合成配方、72 份战利品表（方块 + 宝箱）、群系 / 特征 / 结构全套世界生成 JSON，配方与战利品表经 Datagen 生成。

## 安装

1. 安装对应版本的 Minecraft Forge（47.4.10+）。
2. 将 **GeckoLib** 与本模组 `mimiworld-<版本>.jar` 一同放入 `.minecraft/mods` 文件夹。
3. 启动游戏（客户端与联机服务器都需放置这两个 jar）。

## 开发

- 构建：`gradlew build`；运行开发客户端：`gradlew runClient`。
- 配方 / 战利品表 / 物品标签经 `src/main/java/.../datagen` 生成，修改后请重跑 DataGenerators。
- 贴图资源清单与来源记录见 [纹理名单.md](纹理名单.md)。
