# 米米世界 · 世界观设定

> 对应模组版本：1.0.2（初稿）
>
> 一句话：**米生二界，天堕其一。净界以米为粮，堕界以罪为食；启航者往返其间，替两个世界记住同一个名字。**

---

## 零、导读

米米世界的底色不是「善与恶」，而是「完整与残缺」。

曾经只有一个世界——旧米界。它以「米」为原质，天穹完整，万物丰饶。后来天塌了。塌下来的天压住了地，旧米界被压成一道有顶、无光、永远停在子夜的裂缝，也就是今天的**残堕界**。

而天塌之前，旧米界的「未落之天」被剥离出去，长成了另一个完整的世界——**米米维度**（米米平原）。它纯净、丰饶、循环，像一枚被小心保存下来的种子。

所以两个世界不是「正与邪」，而是**同一粒米的两半**：一半还在天上，一半已经被自己的天压碎。

玩家从净界出发，穿过米米传送门，下到残堕界；再从残堕界带回被污染的材料，在净界重铸成更锋利的剑与更重的甲。**越往下走，越要借堕落的力量；越想救这个世界，越要先把罪背在自己身上。**

## 一、世界结构

```
                         ┌──────────────────────┐
                         │   「米」——万物原质    │
                         └──────────┬───────────┘
                                    │ 初米裂为二界
              ┌─────────────────────┴─────────────────────┐
              │                                           │
     ┌────────▼─────────┐                       ┌─────────▼────────┐
     │  米米维度（净界） │                       │  旧米界（已失名） │
     │  米米平原          │                       │        │          │
     │  天穹完整、有日光  │                       │   「天堕」        │
     │  米树、米矿、米汤  │                       │        ▼          │
     │  土地仍在生长      │                       │  残堕界（堕界）   │
     └────────┬──────────┘                       │  残堕荒原 / 深渊  │
              │                                  │  有顶、无光、子夜 │
              │                                  └────────┬──────────┘
              │        米米之眼 ×12 + 米米传送器           │
              └────────────────  ⇄  ─────────────────────┘
                     堕落台 ×4 + 堕落十字架 ×4（翻转封印的仪式）
```

- **净界**用「米米之眼」与十二座米米传送器往返，泥米是门上的封土。
- **堕界**用四座堕落台与四座堕落十字架摆成 4×4 仪式打开；踩进贴地的紫色星空门即坠落。
- 两界的坐标比例是 1:8——堕界被压扁了，所以你走一步，净界已经走过八步。

## 二、创世：米即是源

太初只有「米」。

米不是粮食，是**原质**。它结出土地，土地长出米树；它结出石头，石头里沉着米矿；它结出水，水是米汤与饭汤；它结出血肉与灵魂，于是有了米哞牛、米羊羊、米哼猪、啄米鸡，也有了米魂。

太初之米为了记住自己，结出一枚「初米」。初米裂为二：

- **向上的一半**长成米米维度：天在上，米在下，四季与潮汐都完整。
- **向下的一半**沉成旧米界：天与地贴得太近，为后来的「天堕」埋下了因。

两界之间原本只隔着一层**泥米**——像给门盖上一层土。封界纪的古人把泥米盖在传送门上，是为了让两界「记得彼此，但不要随便来往」。

## 三、天堕纪事（时间线）

| 纪元 | 名称 | 发生了什么 |
| --- | --- | --- |
| 第一纪 | 初米纪 | 初米裂为二界。净界向上生长，旧米界向下沉落。 |
| 第二纪 | 丰饶纪 | 旧米界文明鼎盛：米城、米神、八位守护者。月在天上，天凤巡游，蛟龙守海，鲛人唱歌。 |
| 第三纪 | **天堕** | 旧米界的天穹塌落，压住了自己的地。月被「噬月」的狼鹫吞去；天凤折喙；天穹碎成「残天翼」。旧米界从此失去名字，成为**残堕界**。 |
| 第四纪 | 残堕纪 | 七道裂缝里长出七种「堕落」；第八种堕落随后成形。八位旧界守护者被**残堕化**，等级从 I 到 VIII。 |
| 第五纪 | 封界纪 | 净界古人以泥米封住缝隙，立十二座米米传送器、十二只米米之眼守护归途；又在残堕界钉下四座堕落台与四座堕落十字架，把堕界锁在地底。 |
| 第六纪 | **启航纪（现在）** | 封印松动。一位持《启航之书》的人离开粮仓，重演旧界的仪式，向下启航。 |

关键点：**封印与开启是同一套仪式。**
八枚锁芯摆正，是锁；摆反，是门。古人留下的「锁」，在启航者手里变成了「路」。这不是失误，而是古人故意的——他们知道，总有一天需要有人下去。

## 四、残堕：未知的污染

### 4.1 它有名字，但没有解释

净界的学者叫它**残堕**（Remnant Fallen），意思是「天堕之后留下的东西」。
堕界的居民不这么叫。他们只说「它」，或者干脆不说。

它不是物质，不是生物，也不是神。它更像一种**未完成**：
把完整啃成残缺，把名字啃成空白，把「有理由的恶」啃成「不需要理由的恶」。

### 4.2 残堕化

污染以「等级」计量，称为**残堕化 I ～ VIII**。等级越高，越接近它的本源。

被残堕化的东西不会变丑，只会**变「不再需要理由」**：
- 它不再问「为什么要吃」，只吃；
- 它不再问「为什么要恨」，只恨；
- 它不再记得自己曾经是什么，只记得「我不是什么」。

八位 Boss 的残堕化等级是固定的：第一到第八，一一对应。它们不是被污染得最重的，而是**被污染得最有秩序的**——这正是最可怕的地方。

### 4.3 三种学说（都未被证实）

1. **天罚说**：天塌是对旧米界的惩罚。残堕是「罚」的残留。
2. **寄生说**：天穹里一直住着某种东西。天塌，是它落地。
3. **遗忘说**：旧米界先忘记了自己的名字，然后才开始崩塌。残堕是「遗忘」的实体。

三种说法互相矛盾，却都指向同一个禁忌：**不要试图给残堕命名。** 你叫出它的名字，它就会开始啃你的名字。

### 4.4 留白

残堕从哪来、有没有意志、为什么第八宗罪龙像它的容器——这些问题在世界观里**故意不回答**。玩家只能通过「混沌不可名状之米界虚无触」的触足、世界之泪、以及残堕界深处那些不该存在的建筑，自己去猜。

## 五、净界：米米维度（米米平原）

**关键词：完整、丰饶、循环、摇篮。**

- 天穹完整，光从上方来，有昼夜与天气。
- 土地是米的：米草、米树、米原木、米石、硬化米、基米；地下沉着米矿、结晶米矿、重结晶米矿、可燃米矿、超懒精华矿。
- 水是汤：米汤泉、饭汤湖、米汤炼药锅、饭汤炼药锅。
- 生物链温和而完整：米哞牛、米羊羊、米哼猪、啄米鸡、贪米鱼、喷米鱼、米莱马；也有米傀儡、嗥米狼、黏米之蛛、米巫、盗米者等不友善者，但整体仍是「可以种回来」的世界。
- **米米宝藏**：十座固定守卫的宝藏（雕米骷髅、爆烈米灵、嗥米狼、糊米古尸、米哼猪尸、米莱马、米米骷髅、没米入、爪巴米者、米巫）。它们是封界纪的「种子库」——古人把旧界的知识、材料与怪物样本封进宝箱，等启航者来取。
- 象征：粮仓、摇篮、还没有被污染的童年。

净界不是「绝对安全」，而是「坏了还能长回来」。这份「可恢复性」，正是它和堕界最大的差别。

---

## 六、堕界：残堕界（残堕荒原）

**关键词：子夜、压迫、饥饿、镜像。**

- 永恒子夜（时间钉死在 18000），有顶、无天光、灼热、坐标比例 1:8。
- 地形由**残堕深渊岩**与**残堕基岩**构成；天塌下来时被压碎的岩层，至今还在缓慢下沉。
- 生态是「被压扁的旧界」：
  - **界天米**：从塌下的天里长出来的米；
  - **化灵米**：被残堕「化」掉的灵；
  - **米蜃**：旧界海市的蜃影；
  - **堕落米凤**：天凤的残羽；
  - **浅染鲛 / 望米伤鲛**：鲛人的残影，一个被染浅了，一个还在望着净界的方向哭；
  - **懒精灵**：唯一在堕界活得很好的生物，因为它什么都不做；
  - **哮噬米狼鹫**：吞月的狼与食腐的鹫合在一起，爪上还挂着月亮的碎屑；
  - **混沌不可名状之米界虚无触**：没人知道它是不是生物，也没人想知道。
  - **污棘花**：开在裂缝上的花，花瓣是「熟棘花瓣」，可以吃。
- 食物以污染调味：天虚棘脑汤、酱香双鲛尾、天脑汁、酱脑、米堕汁、凤肉泥、龙凤花汤、蜃楼幻想、佛幻想、天堕茶……
  吃下去会变强，也会**残堕化**。这是一种自愿的堕落：用代价换力量。
- 象征：被啃食的镜像、罪与饥饿的现在。

**为什么堕界有顶？** 因为旧米界的天塌下来，压在了自己身上。抬头看到的不是天，是天的背面。

**为什么永远是子夜？** 因为月亮被吞了。残堕界的光，全部来自裂缝里渗出的、不属于这个世界的紫。

## 七、九重米阶：洗清，或背负

九级材料科技树，是这个世界观的主干。它不是简单的「越高级越强」，而是**两条路的交汇**：

| 阶 | 材料 | 性质 | 关键词 |
| --- | --- | --- | --- |
| 1 | 米 → 熟米 → 米团 | 净界日常 | 生存 |
| 2 | 饭晶 | 结晶米凝结 | 凝结 |
| 3 | 饭晶合金 | 饭晶 + 米石 | 武装 |
| 4 | 超重结晶 | 高压压实 | 重量 |
| 5 | 复合米饭 | 多种米复合 | 融合 |
| 6 | 清洁复合 | 米果清洁液洗净 | **净化（净之路的顶点）** |
| 7 | 超懒合金 | 超懒精华 | **无为（以逸待劳）** |
| 8 | 天堕锭 / 最懒天堕 | 残堕锭围住破败之心锻造 | **以罪为骨** |
| 9 | 残堕 / 残堕宗罪 | 残堕世界精华 + 终末龙逆鳞 | **背负罪名** |

### 7.1 前六阶是「洗」，后三阶是「背」

- **清洁复合**是净化的极限。再往上，纯净已经无法变强——因为纯净只能「保持」，不能「对抗」。
- 要对抗残堕，必须使用残堕。**天堕锭**是把残堕锭围成一圈、中心嵌进「破败之心」锻出来的；**残堕宗罪套**则直接用残堕世界精华、终末龙逆鳞与精制强化米网打造。
- 这就是世界观的核心矛盾：**救赎必须携带罪。** 你越接近终局，身上的堕落材料越多。你不是站在光里打败黑暗，而是**穿着黑暗去和黑暗讲道理**。

### 7.2 「懒」不是罪

在这个世界里，**懒不是七宗罪之一**，而是一种哲学。

- 超懒合金、最懒天堕、最懒终末龙、懒精灵——「懒」意味着**不妄动**：不与世界的循环对抗，让米替自己生长，让重力替自己落剑。
- 所以「最懒」是最强的材料之一：它以最少的动作，得到最大的结果。
- 这也是米米世界的幽默所在：别的世界用「勤奋」变强，这里用「躺平」变强；但躺平的尽头，是替世界背罪。

## 八、八重堕落：Boss 志

八位 Boss 不是「恶」，而是**坏掉的善**。它们曾是旧米界的八位守护者，天堕时各自接住了一片塌下来的天，于是被残堕化。

### 8.1 第八宗罪：渎天

七宗罪是「人做了什么」。第八宗罪是「人如何审判」。

天塌之后，幸存者抬头问了一句：**「为什么是我们？」**
这个问题没有得到回答，于是它自己长成了一条龙。

第八宗罪龙戴着**堕落王冠**，怀里揣着**堕落之心**与**破败之心**，身上凝着**七宗堕落**。它的罪不是犯了七罪，而是**判了世界有罪**——它认定这个世界活该塌，认定所有幸存者都欠天一个交代。

所以最终战不是单纯的「打死它」。玩家必须用自己一路背下来的罪、用残堕材料打造的剑，回答它的问题：
**这个世界，该不该被判有罪？**

### 8.2 为什么第七 Boss 叫「最懒」

因为它本可以彻底毁掉旧米界，但它**懒得毁干净**。
它随手一收，把世界压成一道裂缝就走了，于是才有了「残堕」——残下来的、堕下去的那一半。

玩家后来用它的鳞、它的胆、它的剑诀锻造天堕装备。这是世界观里最漂亮的一笔：**你穿着「未完成的毁灭」去挑战「未完成的审判」。**

## 九、遗物、仪式与书

### 9.1 圣遗物：借来的罪

八位 Boss 的遗物可以放进**圣遗物**槽位。它们不是「奖励」，而是**借来的罪**：
- **坚韧虎皮**给你护甲，也让你易怒；
- **月有圆缺**给你暴击与攻击，也让你受到更多伤害；
- **虎王之蔑**把一次伤害拆成五笔，慢慢还；
- **领域展开**压制周围敌人的护甲，也压着你自己的呼吸。

用它们的力气，就要承担它们的习性。这是残堕界最公平的规矩。

### 9.2 神遗之书：名字

**神遗之书**记录旧界诸神的真名。残堕能啃掉血肉、记忆、天空，唯独啃不动「被写下来的名字」。

所以净界人写字：米书、米纸、米笔、书米笔。他们把名字写在米纸上，藏进米米宝藏，等启航者来读。

（这也是「遗忘说」最有力的证据：残堕也许不是从天上来，而是从「没有人再叫那个名字」开始。）

### 9.3 传送与封印

- **米米之眼**：能看见世界之间的缝隙。十二只眼插进十二座**米米传送器**，泥米落下，门就开了。这是古人留下的「归途仪式」。
- **泥米**：二界之间的封土。门开了，泥米盖在门上；门碎了，泥米跟着碎。它既是封印，也是路标。
- **堕落台 + 堕落十字架**：八枚锁芯。四座台、四座十字架摆成 4×4，踩进去就是残堕界。古人用它锁门，启航者用它开门。
- **召唤器 / 召唤核心**：重演旧界的「召回应」。小型 → 中型 → 大型 → 最懒，依次唤醒八位守护者。你叫醒它们，它们才想起自己曾经是谁。

### 9.4 深染

用**浸染液**把 Boss 遗物「深染」，能让它记起堕落前的力量：深染残天翼、深染虚无之触、深染天凤之喙、深染噬月狼爪……

深染不是变强，是**变回原样**。原样往往比现在更危险。

### 9.5 两个附魔

- **泣血**：世界之泪的回响。伤口会替世界哭。
- **完美无缺**：净界对「完整」最后的执念。它不修复残缺，它只是拒绝承认残缺。

## 十、玩家：启航者

你不是天选之人。你是**愿意离开粮仓的人**。

《启航之书》是一张单程票。持有它的人，会在净界与堕界之间往返，做三件事：

1. **拾穗者**：在净界种米、采矿、造机器、锻装备。
2. **记录者**：在堕界记下每一个名字——Boss 的、鲛人的、天凤的、甚至连虚无触的。
3. **背罪者**：穿上残堕宗罪套，替世界背下第八宗罪。

你的循环就是世界观：
**净界种田 → 锻造 → 召唤守护者 → 下堕界 → 取残堕材料 → 回净界重铸 → 再下堕界。**

每一次往返，你都更接近真相，也更接近堕落。终局不是「净化残堕界」——那做不到，也不该做。终局是**认罪，然后继续**。

## 十一、主题与基调

- **核心母题**：丰饶 vs 饥饿；完整 vs 残缺；记住 vs 遗忘；洗清 vs 背负。
- **基调反差**：表皮是童话、美食、种田的荒诞可爱（米羊羊、米哼猪、天脑汁、佛幻想、酱脑）；内里是克苏鲁式的未知与七宗罪式的道德重量。**越荒诞，越真实。**
- **米是温柔的暴力**：它养活一切，也定义一切。当米被污染，丰饶本身就成了恐怖。
- **懒是温柔的抵抗**：在最努力的世界里，最懒的东西反而最强；但最强的东西，最后要替世界背罪。
- **不设纯粹的反派**：八位 Boss 都是坏掉的善；第八宗罪龙是「审判」本身。玩家要战胜的不是恶，而是「世界活该塌」这个念头。

## 十二、可扩展的叙事钩子（留白）

以下内容在世界观里保留为「未解」，方便后续版本继续写：

- **第九阶 / 第九宗罪**：残堕世界精华若再提纯一次，会不会出现「第九宗罪」？
- **旧米界的名字**：没人记得。玩家能不能给它取名？
- **米米猴王的真实身份**：它是不是曾经是人？为什么它掉的是下界合金，而不是米？
- **混沌虚无触**：它是残堕的使徒，还是「天」的一部分？
- **世界之泪**：藏在残堕界最深处。它的用途未知。
- **封界纪的古人**：谁建的十二座传送器？为什么要把两个世界分开？
- **懒精灵**：唯一在堕界活得很好的生物。它知道什么，但它懒得说。
- **旧界三神兽**：天凤、噬月狼、蛟龙，只剩残骸。能不能复活？
- **米米神翼 vs 天堕翼**：同一双翅膀的两面，一面向上飞，一面向下坠。
