# 米米世界 · 世界观设定

> 对应模组版本：1.0.3（完整版）
>
> 一句话：**米生二界，天堕其一。净界以米为粮，堕界以罪为食；启航者往返其间，替两个世界记住同一个名字。**

---

## 零、导读

米米世界的底色不是「善与恶」，而是「完整与残缺」。

曾经只有一个世界——旧米界。它以「米」为原质，天穹完整，万物丰饶。后来天塌了。塌下来的天压住了地，旧米界被压成一道有顶、无光、永远停在子夜的裂缝，也就是今天的**残堕界**。

而天塌之前，旧米界的「未落之天」被剥离出去，长成了另一个完整的世界——**米米维度**（米米平原）。它纯净、丰饶、循环，像一枚被小心保存下来的种子。

所以两个世界不是「正与邪」，而是**同一粒米的两半**：一半还在天上，一半已经被自己的天压碎。

玩家从净界出发，穿过米米传送门，下到残堕界；再从残堕界带回被污染的材料，在净界重铸成更锋利的剑与更重的甲。**越往下走，越要借堕落的力量；越想救这个世界，越要先把罪背在自己身上。**

                                    │ 初米裂为二界
              ┌─────────────────────┴─────────────────────┐
              │                                           │
     ┌────────▼─────────┐                       ┌─────────▼────────┐
     │  米米维度（净界） │                       │  旧米界（已失名） │
     │  米米平原          │                       │        │          │
     │  天穹完整、有日光  │                       │   「天堕」        │
     │  米树、米矿、米汤  │                       │        ▼          │
     │  土地仍在生长      │                       │  残堕界（堕界）   │
     └────────┬──────────┘                       │  残堕荒原 / 深渊  │
              │                                  │  有顶、无光、子夜 │
              │                                  └────────┬──────────┘
              │        米米之眼 ×12 + 米米传送器           │

                     堕落台 ×4 + 堕落十字架 ×4（翻转封印的仪式）

- **净界**用「米米之眼」与十二座米米传送器往返，泥米是门上的封土。若传送门已毁，米米之眼会把你送回出生点——它记得的不是坐标，是「家」。
- **堕界**用四座堕落台与四座堕落十字架摆成 4×4 仪式打开；踩进贴地的紫色星空门即坠落。
- 两界的坐标比例是 1:8——堕界被压扁了，所以你走一步，净界已经走过八步。

## 二、创世：米即是源

太初只有「米」。

米不是粮食，是**原质**。它结出土地，土地长出米树；它结出石头，石头里沉着米矿；它结出水，水是米汤与饭汤；它结出血肉与灵魂，于是有了米哞牛、米羊羊、米哼猪、啄米鸡，也有了米魂。

太初之米为了记住自己，结出一枚「初米」。初米裂为二：

- **向上的一半**长成米米维度：天在上，米在下，四季与潮汐都完整。
- **向下的一半**沉成旧米界：天与地贴得太近，为后来的「天堕」埋下了因。

两界之间原本只隔着一层**泥米**——像给门盖上一层土。封界纪的古人把泥米盖在传送门上，是为了让两界「记得彼此，但不要随便来往」。

## 三、天堕纪事（时间线）

| 纪元 | 名称 | 发生了什么 |
| --- | --- | --- |
| 第一纪 | 初米纪 | 初米裂为二界。净界向上生长，旧米界向下沉落。 |
| 第二纪 | 丰饶纪 | 旧米界文明鼎盛：米城、米神、八位守护者。月在天上，天凤巡游，蛟龙守海，鲛人唱歌。剑修在山巅铸剑，厨子在灶前熬汤。 |
| 第三纪 | **天堕** | 旧米界的天穹塌落，压住了自己的地。月被「噬月」的狼鹫吞去；天凤折喙；蛟龙沉海，只留一副爪。天穹碎成「残天翼」。旧米界从此失去名字，成为**残堕界**。 |
| 第四纪 | 残堕纪 | 七道裂缝里长出七种「堕落」；第八种堕落随后成形。八位旧界守护者被**残堕化**，等级从 I 到 VIII。 |
| 第五纪 | 封界纪 | 净界古人以泥米封住缝隙，立十二座米米传送器、十二只米米之眼守护归途；又在残堕界钉下四座堕落台与四座堕落十字架，把堕界锁在地底。剑修的剑法被列为禁卷，十座米米宝藏封存了旧界的火种。 |
| 第六纪 | **启航纪（现在）** | 封印松动。一位持《启航之书》的人离开粮仓，重演旧界的仪式，向下启航。 |

关键点：**封印与开启是同一套仪式。**
八枚锁芯摆正，是锁；摆反，是门。古人留下的「锁」，在启航者手里变成了「路」。这不是失误，而是古人故意的——他们知道，总有一天需要有人下去。

## 四、残堕：未知的污染

### 4.1 它有名字，但没有解释

净界的学者叫它**残堕**（Remnant Fallen），意思是「天堕之后留下的东西」。
堕界的居民不这么叫。他们只说「它」，或者干脆不说。

它不是物质，不是生物，也不是神。它更像一种**未完成**：
把完整啃成残缺，把名字啃成空白，把「有理由的恶」啃成「不需要理由的恶」。

### 4.2 残堕化

污染以「等级」计量，称为**残堕化 I ～ VIII**。等级越高，越接近它的本源。

被残堕化的东西不会变丑，只会**变「不再需要理由」**：
- 它不再问「为什么要吃」，只吃；
- 它不再问「为什么要恨」，只恨；
- 它不再记得自己曾经是什么，只记得「我不是什么」。

八位 Boss 的残堕化等级是固定的：第一到第八，一一对应。它们不是被污染得最重的，而是**被污染得最有秩序的**——这正是最可怕的地方。

玩家在堕界吃下污染的食物、穿戴堕落的材料，也会累积残堕化。这不是惩罚，是**门票**：你想走到最深的地方，就得先让最深处的东西认得你。

### 4.3 三种学说（都未被证实）

1. **天罚说**：天塌是对旧米界的惩罚。残堕是「罚」的残留。
2. **寄生说**：天穹里一直住着某种东西。天塌，是它落地。
3. **遗忘说**：旧米界先忘记了自己的名字，然后才开始崩塌。残堕是「遗忘」的实体。

三种说法互相矛盾，却都指向同一个禁忌：**不要试图给残堕命名。** 你叫出它的名字，它就会开始啃你的名字。

### 4.4 留白

残堕从哪来、有没有意志、为什么第八宗罪龙像它的容器——这些问题在世界观里**故意不回答**。玩家只能通过「混沌不可名状之米界虚无触」的触足、世界之泪、以及残堕界深处那些用磨制残堕深渊岩砌成的、不该存在的建筑，自己去猜。

## 五、净界：米米维度（米米平原）

**关键词：完整、丰饶、循环、摇篮。**

- 天穹完整，光从上方来，有昼夜与天气。
- 土地是米的：米草、米树、米原木、米石、硬化米、基米；地下沉着米矿、结晶米矿、重结晶米矿、可燃米矿、超懒精华矿。
- 水是汤：米汤泉、饭汤湖、米汤炼药锅、饭汤炼药锅。
- 生物链温和而完整：米哞牛、米羊羊、米哼猪、啄米鸡、贪米鱼、喷米鱼、米莱马；也有米傀儡、嗥米狼、黏米之蛛、米巫、盗米者等不友善者，但整体仍是「可以种回来」的世界。

### 5.1 灶上的文明

净界人以「灶」为家。一个村子的中心不是教堂，是锅：

- **搅碎器**与**搅拌器**负责处理食材；
- **铁锅**、**炉灶**、**烤箱**是日常三件套；
- **大煮锅**用来宴请，**巨无霸大大大煮锅**只在节日架起——净界人相信，只要锅够大，就没有熬不下去的日子。

餐具是米做的：米桶、饭桶、大碗、盘子、米木纸盘、盖子、勺子。吃完饭，米果渣还田，米骨磨粉肥田。**净界的循环观不在经书里，在锅里。**

### 5.2 不友善者与盗米者

净界不是没有恶意。嗥米狼在夜里嚎，米巫在雾里熬药，黏米之蛛在树上结网。其中最特别的是**盗米者**：

- 它什么都不要，只要米。杀死它会掉出**盗米之心**——一颗被「想要」填满的心。
- 净界老人说：盗米者是丰饶的影子。丰饶越大，影子越长。它不属于七宗罪，它是七宗罪的**预习**。

### 5.3 米米宝藏：封界纪的种子库

十座固定守卫的宝藏散布在平原上，由十种怪物看守：雕米骷髅、爆烈米灵、嗥米狼、糊米古尸、米哼猪尸、米莱马、米米骷髅、没米入、爪巴米者、米巫。

它们是封界纪的「种子库」——古人把旧界的知识、材料与怪物样本封进宝箱，等启航者来取。**看守者不是狱卒，是书签。** 它们守的不是财宝，是「这里有一页，别忘了翻」。

### 5.4 净界的三件护身物

- **米米图腾**：封界纪发给远行者的替死米偶。它替你把「死」字签走一次。米做的偶，碎的时候不响，像一粒米落地。
- **米米圣盾**：用前四位守护者的遗物合铸——猴王毫毛、虎王利爪、牛王晶角、兔王腥红眼，各配一枚对应阶位的材料，正中放一粒米。挨一下，盾把伤害记成一笔账，转成额外生命值还给你——上限是你生命的四成。**四位守护者没守住旧界，现在它们替你守住你。** 净界的温柔是有限的，但够用。
- **米米之眼**：十二只眼看守归途。门毁了也不要紧，它记得你出生的地方。

象征：粮仓、摇篮、还没有被污染的童年。

净界不是「绝对安全」，而是「坏了还能长回来」。这份「可恢复性」，正是它和堕界最大的差别。

## 六、堕界：残堕界（残堕荒原）

**关键词：子夜、压迫、饥饿、镜像。**

- 永恒子夜（时间钉死在 18000），有顶、无天光、灼热、坐标比例 1:8。
- 地形由**残堕深渊岩**与**残堕基岩**构成；天塌下来时被压碎的岩层，至今还在缓慢下沉。深处散落着**磨制残堕深渊岩**砌成的建筑——没人知道是谁砌的。也许是旧界最后的工匠，也许是残堕自己在模仿「文明」。
- 生态是「被压扁的旧界」：
  - **界天米**：从塌下的天里长出来的米；
  - **化灵米**：被残堕「化」掉的灵；
  - **米蜃**：旧界海市的蜃影；
  - **堕落米凤**：天凤的残羽；
  - **浅染鲛 / 望米伤鲛**：鲛人的残影，一个被染浅了，一个还在望着净界的方向哭。鲛泪是她们唯一还肯交出来的东西；
  - **懒精灵**：唯一在堕界活得很好的生物，因为它什么都不做。它戴着精灵帽，帽子比它聪明；
  - **哮噬米狼鹫**：吞月的狼与食腐的鹫合在一起，爪上还挂着月亮的碎屑；
  - **混沌不可名状之米界虚无触**：没人知道它是不是生物，也没人想知道。它的触足可以吃。这是堕界最诚实的部分；
  - **污棘花**：开在裂缝上的花，花瓣是「熟棘花瓣」，可以吃。
- 食物以污染调味：天虚棘脑汤、酱香双鲛尾、天脑汁、酱脑、米堕汁、凤肉泥、龙凤花汤、蜃楼幻想、佛幻想、天堕茶、油爆虚无触、蛟足炒饭、超级大乱炖……
  吃下去会变强，也会**残堕化**。这是一种自愿的堕落：用代价换力量。
- 象征：被啃食的镜像、罪与饥饿的现在。

**为什么堕界有顶？** 因为旧米界的天塌下来，压在了自己身上。抬头看到的不是天，是天的背面。

**为什么永远是子夜？** 因为月亮被吞了。残堕界的光，全部来自裂缝里渗出的、不属于这个世界的紫。

**堕界料理的本质**：把罪做成菜。净界的厨子熬汤是为了团圆，堕界的「厨子」熬汤是为了忘记。同一口锅，两个方向。

## 七、九重米阶：洗清，或背负

九级材料科技树，是这个世界观的主干。它不是简单的「越高级越强」，而是**两条路的交汇**：

| 阶 | 材料 | 性质 | 关键词 |
| --- | --- | --- | --- |
| 1 | 米 → 熟米 → 米团 | 净界日常 | 生存 |
| 2 | 饭晶 | 结晶米凝结 | 凝结 |
| 3 | 饭晶合金 | 饭晶 + 米石 | 武装 |
| 4 | 超重结晶 | 高压压实 | 重量 |
| 5 | 复合米饭 | 多种米复合 | 融合 |
| 6 | 清洁复合 | 米果清洁液洗净 | **净化（净之路的顶点）** |
| 7 | 超懒合金 | 超懒精华 | **无为（以逸待劳）** |
| 8 | 天堕锭 / 最懒天堕 | 残堕锭围住破败之心锻造 | **以罪为骨** |
| 9 | 残堕 / 残堕宗罪 | 残堕世界精华 + 终末龙逆鳞 | **背负罪名** |

### 7.1 前六阶是「洗」，后三阶是「背」

- **清洁复合**是净化的极限。再往上，纯净已经无法变强——因为纯净只能「保持」，不能「对抗」。
- 要对抗残堕，必须使用残堕。**天堕锭**是把残堕锭围成一圈、中心嵌进「破败之心」锻出来的；**残堕宗罪套**则直接用残堕世界精华、终末龙逆鳞与精制强化米网打造。
- 这就是世界观的核心矛盾：**救赎必须携带罪。** 你越接近终局，身上的堕落材料越多。你不是站在光里打败黑暗，而是**穿着黑暗去和黑暗讲道理**。

### 7.2 第九阶的三件器物

残堕宗罪套之外，第九阶还有三件武器：

- **残堕宗罪之弓**：把七种堕落拉成一根弦；
- **残堕崩解之镐**：镐落之处，方块记起自己曾经是米；
- **残堕逆鳞之剑**：用终末龙的逆鳞开锋。龙最软的地方，成了世界最硬的地方。

### 7.3 「懒」不是罪

在这个世界里，**懒不是七宗罪之一**，而是一种哲学。

- 超懒合金、最懒天堕、最懒终末龙、懒精灵——「懒」意味着**不妄动**：不与世界的循环对抗，让米替自己生长，让重力替自己落剑。
- 所以「最懒」是最强的材料之一：它以最少的动作，得到最大的结果。
- 这也是米米世界的幽默所在：别的世界用「勤奋」变强，这里用「躺平」变强；但躺平的尽头，是替世界背罪。

## 八、剑道：以血淬剑，以懒收刀

九重米阶是「甲」的路，剑道是「剑」的路。两条路平行，最后在最懒天堕剑上交汇。

### 8.1 剑道三物

- **剑意**：剑还没成形时的那一口气。**上古剑意**以四颗龙头为框、末影水晶为芯、校准幽匿感测体为耳——先学会听，才配谈杀。
- **剑魄**：剑意的骨头。上古剑意裹上远古残骸与可燃固态物，烧成**远古剑魄**；再以超懒合金重铸，成**太古剑魄**。魄越古，越沉。
- **淬剑液**：剑的水。**血瓶**（任意血肉封进玻璃瓶）兑入米桶、米果清洁液与清洁米沉离液——以血淬火，以净收口。剑道从一开始就承认：要见血，也要洗净。

### 8.2 鉴玉：给剑取名

剑修不给剑开锋，先给剑**取名**：

- **神玉**：龙息封住紫水晶，是「天」的印；
- **金米玉**：神玉裹上重结晶米与金锭、以清洁复合锭压角，是「米」的印；
- **结晶米玉**：金米玉再洗一遍，是「净」的印；
- **神剑鉴玉**：太古剑魄嵌进八面金米玉——鉴，是「认」。认出这把剑是哪一把，它才肯出鞘。

残堕啃不动写下来的名字，剑修因此相信：**被鉴过的剑，不会被世界弄丢。**

### 8.3 禁卷与剑法

- **剑法禁卷**：米纸、米书与恶魂之泪写成。封界纪时，剑修主张「与其封门，不如杀下去」，被主流的封印派列为禁术。卷里的每一个字都是一滴哭出来的泪——那是主张杀下去的人，最后也没能忍住的眼泪。
- **超懒剑法**：禁卷的解开方式，却是「懒」。金米玉围一圈，超懒合金压底，把禁卷和鉴玉合在一起——**最凶的剑法，教的是最懒的出剑**：不出则已，一出就收。

### 8.4 神剑与赝品

- **超懒神剑**：超懒合金剑 + 上古剑意 + 淬剑液。剑道的正果。
- **终末剑诀**：龙头与结晶米玉参悟超懒剑法而得——最懒终末龙毁世时用的那一招的心法。
- **最懒天堕剑（赝品）**：超懒神剑按终末剑诀重铸。能劈开残堕界最硬的岩层。

但请注意它的来历：它是**赝品**。

真正的最懒天堕剑，随最懒终末龙一起坠进了残堕界。你手里这把，是剑修一脉凭着剑诀「凭记忆重打的」。赝品尚且如此，真品在谁手里、还是否认得回家的路——这是剑道留给启航者的最后一个问题。

### 9.1 头颅：被钉住的名字

八位守护者都会留下头颅。净界人相信**头记得名字**：

- 把头颅挂在墙上，是把它的名字钉回世界——残堕啃不动被写下来的名字，也啃不动被挂起来的头。
- 用头颅可以重新孵出对应的生物蛋。**记住名字，就能唤回。** 你杀死的每一位守护者，都可以在你手里重新醒来——只是醒来时，它仍是残堕化的。唤回不是治愈，是「我记得你」。

### 9.2 第八宗罪：渎天

七宗罪是「人做了什么」。第八宗罪是「人如何审判」。

天塌之后，幸存者抬头问了一句：**「为什么是我们？」**
这个问题没有得到回答，于是它自己长成了一条龙。

第八宗罪龙戴着**堕落王冠**，怀里揣着**堕落之心**与**破败之心**，身上凝着**七宗堕落**。它的罪不是犯了七罪，而是**判了世界有罪**——它认定这个世界活该塌，认定所有幸存者都欠天一个交代。

龙陨之后，这些罪物可以被重铸：重铸**七宗堕落**，要以堕落王冠、堕落之心、终末剑诀与下界之星为料，再以一颗**盗米之心**为引——最不起眼的「想要」，正是七宗堕落共同的起点。盗米者是七宗罪的预习，也是七宗堕落的钥匙。

所以最终战不是单纯的「打死它」。玩家必须用自己一路背下来的罪、用残堕材料打造的剑，回答它的问题：
**这个世界，该不该被判有罪？**

### 9.3 为什么第七 Boss 叫「最懒」

因为它本可以彻底毁掉旧米界，但它**懒得毁干净**。
它随手一收，把世界压成一道裂缝就走了，于是才有了「残堕」——残下来的、堕下去的那一半。

玩家后来用它的鳞、它的胆、它的剑诀锻造天堕装备。这是世界观里最漂亮的一笔：**你穿着「未完成的毁灭」去挑战「未完成的审判」。**

## 十、遗物、仪式与书

### 10.1 圣遗物：借来的罪

八位 Boss 的遗物可以放进**圣遗物**槽位。它们不是「奖励」，而是**借来的罪**：
- **火眼金睛**给你夜视，也让你再也看不见黑暗——有些东西，看不见比看见更危险；
- **如意**伸长你的手臂，也伸长你的贪心；
- **坚韧虎皮**给你护甲，也把护甲折成攻击的薪柴；
- **虎王之蔑**把一次伤害拆成五笔，慢慢还——债没有消失，只是分期；
- **月有圆缺**给你暴击与攻击，也让你受更重的伤——月亮从不圆满，它只是轮流缺给不同的人看；
- **猩红竖眼**让周围的怪物发光，按下按键，你瞬移到它身后——猎手的眼睛，从来不分敌我；
- **领域展开**压制周围敌人的护甲，也压着你自己的呼吸；
- **逆鳞龙胆**给你近乎无敌的坚韧——单次伤害不超过生命的两成。龙的软肋，成了你的铠甲。

用它们的力气，就要承担它们的习性。这是残堕界最公平的规矩。

### 10.2 神遗之书：名字

**神遗之书**记录旧界诸神的真名。残堕能啃掉血肉、记忆、天空，唯独啃不动「被写下来的名字」。

所以净界人写字：米书、米纸、米笔、书米笔。他们把名字写在米纸上，藏进米米宝藏，等启航者来读。

（这也是「遗忘说」最有力的证据：残堕也许不是从天上来，而是从「没有人再叫那个名字」开始。）

### 10.3 三双翅膀

- **米米神翼**：净界的天。以米米幻翼膜织成，穿上它，你能像创世一样飞行——向上的那一双；
- **超懒神翼胸甲**：米米神翼缝进超懒合金胸甲。懒得扇，但一直在飞——不动的那一双；
- **天堕翼胸甲**：用残天翼拼成。它不向上飞，它向下坠，但坠得极稳——向下的那一双。

同一双翅膀的三面：向上、不动、向下。正好是两个世界之间，一个启航者的全部方向。

### 10.4 传送与封印

- **米米之眼**：能看见世界之间的缝隙。十二只眼插进十二座**米米传送器**，泥米落下，门就开了。这是古人留下的「归途仪式」。门若已毁，它送你回出生点——归途的尽头不是门，是家。
- **泥米**：二界之间的封土。门开了，泥米盖在门上；门碎了，泥米跟着碎。它既是封印，也是路标。
- **堕落台 + 堕落十字架**：八枚锁芯。四座台、四座十字架摆成 4×4，踩进去就是残堕界。古人用它锁门，启航者用它开门。

### 10.5 召唤：重演「召回应」

- **召唤器**：小型 → 中型 → 大型 → 最懒，四级仪式依次重演旧界的「召回应」，唤醒八位守护者。
- **召唤核心 → 高级召唤核心 → 最懒召唤核心**：回应的心脏。混合结晶熔成熔融混合结晶，是一声「应答」从浑浊到清澈的过程。
- 你叫醒它们，它们才想起自己曾经是谁。**召唤不是挑衅，是认亲。**
- 八枚生物蛋以同源的液体配方凝成——八位守护者，同一种堕落，八个名字。

### 10.6 深染

用**浸染液**把遗物「深染」，能让它记起堕落前的力量：深染残天翼、深染虚无之触、深染天凤之喙、深染噬月狼爪、深染鲛泪、深染蛟龙爪、深染蜃楼骨、深染精灵帽……

深染不是变强，是**变回原样**。原样往往比现在更危险。

### 10.7 两个附魔

- **泣血**：世界之泪的回响。伤口会替世界哭。
- **完美无缺**：净界对「完整」最后的执念。它不修复残缺，它只是拒绝承认残缺。

## 十一、故事正文：从初米到启航

> 本章为完整主线叙事。前文各章是「设定」，本章是「故事」。

### 第一章 · 初米

太初没有天地，只有一粒米。

米不知道自己是什么，于是它把自己种了下去。种下去的地方长出土地，土地举起天空；米渗进石头，成了矿；米化进水里，成了汤；米有了心跳，成了万物。

米还是想知道自己是什么。它结出一枚**初米**——一面镜子。镜子太重，裂成两半：

向上的一半轻，飘成了**米米维度**。那里天是完整的，米树一年四熟，米汤泉冬暖夏凉。

向下的一半重，沉成了**旧米界**。那里天与地贴得很近，近得人们一抬头，就能看清天上的裂纹。旧米界的人管那些裂纹叫「天的皱纹」。他们说：天老了，所以我们要替天好好活。

他们不知道，皱纹不是老，是要塌。

### 第二章 · 丰饶

旧米界的文明，是在天的裂缝底下长起来的。

他们建了米城，城墙用重结晶米砌成，夜里会发光。他们立了米神，神像不大，放在每家每户的灶台上——**旧米界的神不管天，管饭。**

八位守护者分管八方：

山林归猴王，田畴归虎王，矿脉归牛王，月庭归兔王，河海归天青蟒，长生归夔，天穹归终末龙，审判归那位没有名字的龙——它负责在万物做错事时，说出「你错了」。

天上还有三神兽：天凤巡游报时，噬月狼守着月亮不贪食，蛟龙镇海不泛滥。鲛人在海边唱歌，唱的是净界的方向——那时两界只隔一层泥米，歌声能穿过去。

那是丰饶纪。旧米界的人以为，日子会一直这样过下去。

### 第三章 · 天堕

天塌的那天，没有雷声。

先是月亮不见了。噬月狼忽然发疯，一口吞了它守了一辈子的月亮——后来没人知道它是被残堕化的，还是它想用身体替世界存住最后一颗月亮。

然后天凤从天上掉下来，喙先着地，折了。

然后天塌了。

八位守护者各自接住了一片塌下来的天。天太重，重到接住它的那一刻，他们就不再是他们了——**接住天的手，再也松不开；松开手的那个，就不再是守护者。**

旧米界被压进自己的影子里，成了一道有顶的裂缝。天与地贴在一起，像一本合上的书。书里的字，从那时起开始被人遗忘。

最后一个忘记的是名字。旧米界的人先是想不起神叫什么，然后想不起城叫什么，最后想不起**自己这个世界叫什么**。

名字没了。于是它来了。

### 第四章 · 残堕

没人看见它是怎么来的。裂缝里先是渗出紫色的光，然后光里长出七种东西：傲慢、暴怒、嫉妒、色欲、贪婪、暴食、懒惰——七道裂缝，七种堕落，一一钻进八位守护者的身体里。

为什么是八位守护者？因为**接住天的人，手里有天的碎片**。它顺着碎片爬进去，像水顺着裂缝渗进地基。

第八种堕落成形得最晚。它不来自裂缝，来自幸存者的嘴。

天塌之后，活下来的人聚在废墟上，问了同一个问题：**「为什么是我们？」**

问题没有人回答，于是问题自己活了。它长成第八条龙，戴上王冠，开始审判：**是你们。世界活该塌。你们都有罪。**

八位守护者，一级一级地残堕化。最轻的忘了仁慈，最重的忘了名字。第八位什么都没忘——它记得一切，所以它审判一切。

### 第五章 · 封界

净界是看着旧米界塌的。

天塌的震动传到泥米上，净界的天空晃了三晃。净界的古人开了一个很长的会，会上有两派：

**封印派**说：把门封死，让堕界自己沉下去。我们保住种子，就是保住世界。

**剑修派**说：封门是等死。下界的堕落迟早渗上来。与其封，不如杀下去，趁它还认不出我们的名字。

封印派赢了。剑修的法卷被收走，封进米书，列为**禁卷**；剑修的玉被砸碎，碎片撒进米米宝藏；剑修中最顽固的一脉，带着未完成的剑谱下了堕界，再没有回来。终末剑诀的最后一页，是他们用血写的。

封印派立了十二座传送器，造了十二只米米之眼，把泥米盖在门上。又下堕界，钉下四座堕落台、四座堕落十字架——八枚锁芯，把堕界锁在地底。

锁门的那位老人在最后一枚锁芯上留了一句话：

**「摆正，是锁。摆反，是门。我们锁它，是因为我们不敢下去。你们若敢，就摆反它。」**

然后把十座宝藏埋进平原，把旧界的名字写进神遗之书，把《启航之书》放在粮仓最显眼的架子上。

封界纪结束。净界继续种田。米继续长。没有人再提旧米界——**除了每年米熟的时候，老人们会朝着地底的方向，撒一把米。**

### 第六章 · 启航

很多年过去，封印松了。

先是泥米开始往下掉渣。然后是夜里有人听见地底传来歌声——是鲛人的调子，但歌词已经被啃得只剩气声。

然后，《启航之书》被人从架子上拿了下来。

没有人知道拿起书的人是谁。也许是一个厌倦了种田的人，也许是一个听见了歌声的人，也许只是一个想把第八把椅子摆反的人。书里只有三句话：

**下去。记住。回来。**

持书的人带上米米图腾和米米之眼，背上一口大煮锅，插下十二只眼睛，走进了光门。

净界的人在他身后喊：「你下去干什么？」

他没有回头。他说：**「下去问问，我们该不该有罪。」**

### 终章 · 认罪与记住

启航者的路，是一条不断往返的路：

在净界种田、采矿、锻甲，用搅碎器和搅拌器把日子磨细；下堕界，吃被污染的食物，穿被污染的甲，让残堕化一点点爬上皮肤，换取走进更深处的资格。

一路唤醒八位守护者。每杀一位，就把它的头颅带回净界，挂在墙上。墙挂满了。八颗头颅在夜里轻轻响，像八粒没煮熟的米。

最后，在最深的地方，启航者见到了第八宗罪龙。

龙问他：**「这个世界，该不该被判有罪？」**

启航者看了看自己的装备：残堕宗罪的头盔里，衬着净界的米网；天堕锭的剑刃上，淬着净界的清洁液；背包里装着米米大杂烩，和八位守护者的头。

他回答：

**「该。我们都接住过塌下来的天，都松过手，都忘过名字。罪是有的。」**

龙的爪抬了起来。

**「但罪不是结论，是遗产。你判世界有罪，是因为你只看得见罪。我穿着罪走了一路，我看见的是：罪能被锻成甲，能被杀死，能被挂在墙上，能被记住。」**

**「你问该不该有罪——该。你问该不该塌——不该。这两句话不矛盾。这两句话加起来，叫活着。」**

那一战打了很久。最后，第八宗罪龙倒下时，王冠滚落在地，七宗堕落散成七道微光，飞回七道裂缝里。裂缝没有合上——**裂缝永远不会合上。** 但从那天起，裂缝里渗出的紫，淡了一点。

启航者捡起堕落之心与破败之心。两颗心在他手里，一颗还在审判，一颗已经累了。

他把它们都收好。然后他做了一件没有人做过的事：

他展开神遗之书，在空白的那一页，给旧米界写下了一个新的名字。

名字是什么，由每一位启航者自己写。**写下名字的那一刻，遗忘说被推翻了一半；剩下的一半，要等下一位启航者。**

启航者回到净界。米还在长，锅还在熬，天还在上面。

他把《启航之书》放回粮仓的架子上，在书的最后一页补了第四句话：

**「下去。记住。回来。——然后，把名字留给下一个下去的人。」**

---

## 十二、玩家：启航者

你不是天选之人。你是**愿意离开粮仓的人**。

《启航之书》是一张单程票。持有它的人，会在净界与堕界之间往返，做三件事：

1. **拾穗者**：在净界种米、采矿、造机器、锻装备。
2. **记录者**：在堕界记下每一个名字——Boss 的、鲛人的、天凤的、甚至连虚无触的。
3. **背罪者**：穿上残堕宗罪套，替世界背下第八宗罪，然后给旧米界重新取名。

你的循环就是世界观：
**净界种田 → 锻造 → 召唤守护者 → 下堕界 → 取残堕材料 → 回净界重铸 → 再下堕界。**

每一次往返，你都更接近真相，也更接近堕落。终局不是「净化残堕界」——那做不到，也不该做。终局是**认罪，记住，然后继续**。

## 十三、主题与基调

- **核心母题**：丰饶 vs 饥饿；完整 vs 残缺；记住 vs 遗忘；洗清 vs 背负。
- **基调反差**：表皮是童话、美食、种田的荒诞可爱（米羊羊、米哼猪、天脑汁、佛幻想、酱脑、巨无霸大大大煮锅）；内里是克苏鲁式的未知与七宗罪式的道德重量。**越荒诞，越真实。**
- **米是温柔的暴力**：它养活一切，也定义一切。当米被污染，丰饶本身就成了恐怖。
- **懒是温柔的抵抗**：在最努力的世界里，最懒的东西反而最强；但最强的东西，最后要替世界背罪。
- **剑是温柔的承认**：剑道以血淬剑、以懒收刀——承认要见血，也承诺会洗净；追求至强，也铭记克制。
- **名字是最后的城墙**：残堕啃得动天，啃不动名字。写下的（神遗之书）、挂起的（头颅）、被叫出口的（召唤），都是记住。
- **不设纯粹的反派**：八位 Boss 都是坏掉的善；第八宗罪龙是「审判」本身。玩家要战胜的不是恶，而是「世界活该塌」这个念头。

## 十四、可扩展的叙事钩子（留白）

以下内容在世界观里保留为「未解」，方便后续版本继续写：

- **最懒天堕剑的真品**：启航者锻出的只是赝品。真品随最懒终末龙坠入残堕界最深处。它现在还认主吗？还是被第八宗罪龙收进了王座？
- **剑修一脉的下落**：带着未完成剑谱下堕界的那一支，死绝了吗？磨制残堕深渊岩的建筑，会不会是他们的手笔？
- **第九阶 / 第九宗罪**：残堕世界精华若再提纯一次，会不会出现「第九宗罪」？
- **米米猴王的真实身份**：它是不是曾经是人？为什么它掉的是下界合金，而不是米？
- **混沌虚无触**：它是残堕的使徒，还是「天」的一部分？
- **世界之泪**：藏在残堕界最深处。它的用途未知。它与「泣血」附魔同源——世界哭过的伤口，也能成为武器。
- **封界纪的古人**：谁建的十二座传送器？那位在锁芯上留话的老人，叫什么名字？
- **懒精灵**：唯一在堕界活得很好的生物。它知道什么，但它懒得说。
- **旧界三神兽**：天凤、噬月狼、蛟龙，只剩残骸。深染能让遗物变回原样——能不能让神兽复活？
- **噬月狼的月亮**：它吞下去的月亮还在它肚子里吗？残堕界若再升起月亮，子夜会不会结束？
- **启航者写下的名字**：每个玩家写的不一样。残堕界认哪个？
