# 米米世界 (MimiWorld)

> 一个以「米」为主题的中型 Minecraft Forge 模组：新增围绕稻米展开的材料、机器、装备、生物与 Boss，并附带一个独立的「米米维度」。

A medium-sized rice-themed Minecraft Forge mod that adds a full progression of rice materials, machines, gear, creatures and bosses, plus a standalone "Mimi" dimension.

---

## 简介

米米世界把原版 Minecraft 的整套玩法「米化」：从种植、加工、冶炼到制造成品装备，构建了一条完整的稻米产业链；同时新增了数十种米主题生物与七个可挑战的 Boss。模组大量使用 [GeckoLib](https://github.com/bernie-g/geckolib) 制作自定义 3D 模型与动画，并配套数据包驱动的维度、群系与结构生成。

- 模组 ID：`mimiworld`
- 目标平台：Minecraft **1.20.1** / Minecraft Forge **47.4.10+**
- 硬性前置：**GeckoLib 4.7+**

## 内容总览

### 农业与材料体系

- **米树与米草**：米原木、米木板、米树叶、米树苗、米草，可自然生成米树林。
- **数百种物品**：从 `米 → 熟米 → 米团` 的基础食物链，到结晶米、可燃米、米麻、米网、米饭合金等各阶段中间材料，构成多级加工体系。
- **多条装备材料线**：饭晶、超结晶、超重结晶、复合米饭、清洁复合、超懒合金、最懒天堕，每线含剑 / 弓 / 全套盔甲 / 镐 / 箭等成套装备；另有「残堕宗罪」套装与「最懒天堕」套装。
- **特色消耗品**：米米图腾（免死）、米米之眼、米米传送器、香袋调料、各式米主题料理等。

### 加工与工作方块

模组提供大量功能性工作方块：

- 造米机、锤米台 / 高级锤米台、压饭机
- 电离台、沉淀台、离解台、碾磨台、杵界台、凝锭台
- 铸剑台、铸甲台、铸弓台、淬剑台、汲血台
- 搅碎器、搅拌器、多输入 / 双输入处理器、栅格合成台
- 煮锅系列：小煮锅 → 煮锅 → 大煮锅 → 超大煮锅 → 巨无霸大大大煮锅，另有铁锅、烤箱、锅 / 大锅等烹饪设备

### 生物

- **友好生物**：米羊羊、啄米鸡、米哞牛、米哼猪、米傀儡、嗥米狼、米莱马。
- **水生生物**：贪米鱼、喷米鱼（可用水桶捕捞，生成于河流 / 海洋）。
- **敌对生物**：盗米者、黏米之蛛、米米骷髅、糊米古尸、爪巴米者、米巫、没米入、爆烈米灵、雕米骷髅、米哼猪尸、米魂、界天米、污棘花、混沌虚无触、堕落米凤、化灵米、浅染鲛、望米伤鲛、米蜃、懒精灵、哮噬米狼鹫等。
- **Boss 阵容**（各具独立技能、动画与专属掉落）：
  1. 米米猴王
  2. 饭晶虎王
  3. 超晶牛王
  4. 重晶兔王
  5. 复晶天青蟒
  6. 清洁长命夔
  7. 最懒终末龙

  另有召唤器（小型 / 中型 / 大型 / 最懒召唤器）用于按需召唤。

### 维度与群系

- **米米维度**：独立维度（`data/mimiworld/dimension` 与 `dimension_type`），含米米平原群系与米树地物生成。
- 通过「米米传送器」等物品进入。

### 整合与兼容

- 大量模型 / 动画由 **GeckoLib** 驱动（自定义生物、动画方块、立体盔甲等）。

| 侧别 | 客户端与服务端均需安装 |

## 安装

1. 安装对应版本的 Minecraft Forge（47.4.10+）。
2. 将 **GeckoLib** 与本模组 `mimiworld-<版本>.jar` 一同放入 `.minecraft/mods` 文件夹。
3. 启动游戏（客户端与联机服务器都需放置这两个 jar）。
